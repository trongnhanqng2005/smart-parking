# Smart Parking

Foundation repository for the Smart Parking system. Approved business workflows are not implemented yet.

## Components

- `backend/` — Spring Boot backend
- `gate-desktop/` — .NET WinForms gate application
- `ai-service/` — FastAPI AI service foundation
- `docs/` — approved project, business, architecture, and database documentation

See [project documentation](docs/README.md) for the documentation map and [AI service README](ai-service/README.md) for its local setup instructions.
